# 🥪 مشروع ساندوتش كورة | Sandwich Kora Project

## 📝 الوصف | Description

مشروع **ساندوتش كورة** هو موقع رياضي عربي شامل يعرض نتائج المباريات، ترتيب الفرق، وأخبار الدوريات بطريقة منظمة وسهلة التصفح.  
يهدف إلى تقديم محتوى رياضي محدث باستخدام تقنيات الويب الحديثة، مع دعم كامل للغة العربية.

**Sandwich Kora** is a modern Arabic sports website that displays match results, team rankings, and league news in a structured and user-friendly format.  
It aims to deliver updated sports content using clean design and modern web technologies.

---

## 🧰 التقنيات المستخدمة | Technologies Used

- HTML5 / CSS3 / SCSS
- JavaScript / jQuery / DataTables
- Netlify CMS (لإدارة المحتوى)
- GitHub Pages / Netlify (للنشر)
- Git / GitHub (لإدارة النسخ)
